### 其他语法

1. **特殊语法**：
   - 转义字符：在特殊符号前加 `\` (如 `\_` 避免斜体)
   - 脚注：正文`[1](@ref)`+底部`[1](@ref): 注释内容`

2. **代码块**
    \`\`\`c
    #include <stdio.h>
    
    int main
    {
        printf(Hello Word);
        return 0;
    }
    \`\`\`

    - 演示
    ```c
    #include <stdio.h>
    
    int main
    {
        printf(Hello Word);
        return 0;
    }
    ```
3. **插入图片**：
    - 语法：`![自定义文本](图片URL)`
    - 示例：![自定义文本](图片URL)

4. **分隔线**：
   - 语法：`---`
    - 示例：
---

5. **文本**：
   - 语法：`- 文本`
   - 示例：
   - 文本

6. **提示语法**：
   - 语法：
```
> [!TIP]
> 这是自定义提示内容，支持**Markdown**语法！
```
    - 示例：

> 这是自定义提示内容，支持**Markdown**语法！
